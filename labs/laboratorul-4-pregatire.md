# Laboratorul 4: exerciții pregătitoare

1. Se citește un număr întreg n (0 < n < 100), apoi n numere întregi într-un array. Elaborați un program care afișează numerele pe un singur rând, separate prin spațiu.

Date de intrare:

```
5
3 7 1 9 4
```

Date de ieșire:

```
3 7 1 9 4
```

2. Se citește un număr întreg n (0 < n < 100), apoi n numere întregi într-un array. Elaborați un program care afișează elementele aflate pe pozițiile pare. Pozițiile se numerotează de la 0.

Date de intrare:

```
6
5 8 2 9 4 1
```

Date de ieșire:

```
5 2 4
```

3. Se citește un număr întreg n (0 < n < 100), apoi n note (numere întregi de la 1 la 10) într-un array. Elaborați un program care afișează suma notelor și media lor, cu două zecimale.

Date de intrare:

```
4
8 9 10 7
```

Date de ieșire:

```
Suma: 34
Media: 8.50
```

4. Se citește un număr întreg n (0 < n < 100), apoi n numere întregi într-un array. Elaborați un program care afișează cel mai mare număr și poziția lui. Pozițiile se numerotează de la 0. Dacă maximul apare de mai multe ori, se afișează prima lui apariție.

Date de intrare:

```
6
4 12 5 12 3 8
```

Date de ieșire:

```
Maximul este 12, la pozitia 1
```

5. Se citește un număr întreg n (0 < n < 100), apoi n numere întregi într-un array. Elaborați un program care afișează câte numere pare conține array-ul și care sunt acestea.

Date de intrare:

```
6
1 4 7 10 13 16
```

Date de ieșire:

```
3 numere pare: 4 10 16
```

6. Se citește un număr întreg n (0 < n < 100), apoi n numere întregi într-un array, apoi un număr x. Elaborați un program care afișează "Gasit" dacă x se află în array și "Negasit" în caz contrar.

Date de intrare:

```
5
2 9 6 3 1
6
```

Date de ieșire:

```
Gasit
```

Date de intrare:

```
5
2 9 6 3 1
7
```

Date de ieșire:

```
Negasit
```

7. Se citesc n și m (n, m < 10), apoi elementele unei matrice de numere întregi cu n linii și m coloane. Elaborați un program care afișează matricea sub formă de tabel, câte o linie a matricei pe fiecare rând.

Date de intrare:

```
2 3
1 2 3
4 5 6
```

Date de ieșire:

```
1 2 3
4 5 6
```

8. Se citesc n și m (n, m < 10), apoi elementele unei matrice de numere întregi cu n linii și m coloane. Elaborați un program care afișează suma tuturor elementelor matricei.

Date de intrare:

```
2 2
5 1
3 2
```

Date de ieșire:

```
Suma: 11
```

9. Se citesc n și m (n, m < 10), apoi elementele unei matrice de numere întregi cu n linii și m coloane. Elaborați un program care afișează, pentru fiecare linie, suma elementelor de pe ea. Liniile se numerotează de la 0.

Date de intrare:

```
3 3
1 2 3
4 5 6
7 8 9
```

Date de ieșire:

```
Linia 0: 6
Linia 1: 15
Linia 2: 24
```

10. Se citește n (n < 10), apoi elementele unei matrice pătratice de numere întregi cu n linii și n coloane. Elaborați un program care afișează elementele de pe diagonala principală și suma lor. Diagonala principală conține elementele aflate pe linia i și coloana i.

Date de intrare:

```
3
2 0 1
4 7 3
5 6 9
```

Date de ieșire:

```
Diagonala principala: 2 7 9
Suma: 18
```

11. Se citește un număr întreg n (n < 10). Elaborați un program care construiește o matrice pătratică n × n în care elementul de pe linia i și coloana j este (i + 1) * (j + 1), apoi o afișează. Elementele nu se citesc, ci se calculează.

Date de intrare:

```
3
```

Date de ieșire:

```
1 2 3
2 4 6
3 6 9
```
