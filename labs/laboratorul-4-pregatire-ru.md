# Лабораторная работа 4: подготовительные упражнения

1. Считывается целое число n (0 < n < 100), затем n целых чисел в array. Разработайте программу, которая выводит числа в одной строке через пробел.

Входные данные:

```
5
3 7 1 9 4
```

Выходные данные:

```
3 7 1 9 4
```

2. Считывается целое число n (0 < n < 100), затем n целых чисел в array. Разработайте программу, которая выводит элементы, стоящие на чётных позициях. Позиции нумеруются с 0.

Входные данные:

```
6
5 8 2 9 4 1
```

Выходные данные:

```
5 2 4
```

3. Считывается целое число n (0 < n < 100), затем n оценок (целые числа от 1 до 10) в array. Разработайте программу, которая выводит сумму оценок и их среднее значение с двумя знаками после запятой.

Входные данные:

```
4
8 9 10 7
```

Выходные данные:

```
Сумма: 34
Среднее: 8.50
```

4. Считывается целое число n (0 < n < 100), затем n целых чисел в array. Разработайте программу, которая выводит наибольшее число и его позицию. Позиции нумеруются с 0. Если максимум встречается несколько раз, выводится его первое вхождение.

Входные данные:

```
6
4 12 5 12 3 8
```

Выходные данные:

```
Максимум 12, на позиции 1
```

5. Считывается целое число n (0 < n < 100), затем n целых чисел в array. Разработайте программу, которая выводит, сколько чётных чисел содержит array, и сами эти числа.

Входные данные:

```
6
1 4 7 10 13 16
```

Выходные данные:

```
Чётных чисел 3: 4 10 16
```

6. Считывается целое число n (0 < n < 100), затем n целых чисел в array, затем число x. Разработайте программу, которая выводит "Найдено", если x находится в array, и "Не найдено" в противном случае.

Входные данные:

```
5
2 9 6 3 1
6
```

Выходные данные:

```
Найдено
```

Входные данные:

```
5
2 9 6 3 1
7
```

Выходные данные:

```
Не найдено
```

7. Считываются n и m (n, m < 10), затем элементы матрицы целых чисел из n строк и m столбцов. Разработайте программу, которая выводит матрицу в виде таблицы, по одной строке матрицы на каждой строке вывода.

Входные данные:

```
2 3
1 2 3
4 5 6
```

Выходные данные:

```
1 2 3
4 5 6
```

8. Считываются n и m (n, m < 10), затем элементы матрицы целых чисел из n строк и m столбцов. Разработайте программу, которая выводит сумму всех элементов матрицы.

Входные данные:

```
2 2
5 1
3 2
```

Выходные данные:

```
Сумма: 11
```

9. Считываются n и m (n, m < 10), затем элементы матрицы целых чисел из n строк и m столбцов. Разработайте программу, которая для каждой строки выводит сумму её элементов. Строки нумеруются с 0.

Входные данные:

```
3 3
1 2 3
4 5 6
7 8 9
```

Выходные данные:

```
Строка 0: 6
Строка 1: 15
Строка 2: 24
```

10. Считывается n (n < 10), затем элементы квадратной матрицы целых чисел из n строк и n столбцов. Разработайте программу, которая выводит элементы главной диагонали и их сумму. Главная диагональ содержит элементы, стоящие в строке i и столбце i.

Входные данные:

```
3
2 0 1
4 7 3
5 6 9
```

Выходные данные:

```
Главная диагональ: 2 7 9
Сумма: 18
```

11. Считывается целое число n (n < 10). Разработайте программу, которая строит квадратную матрицу n × n, в которой элемент в строке i и столбце j равен (i + 1) * (j + 1), затем выводит её. Элементы не считываются, а вычисляются.

Входные данные:

```
3
```

Выходные данные:

```
1 2 3
2 4 6
3 6 9
```
